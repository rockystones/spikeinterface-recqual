Blackrock Utah array · hardware to data file

The electrode number is not the channel number

A 96-electrode Utah array records 96 channels, and almost none of them keep the same number along the way. Electrode 78 is channel 1. This page follows one signal through all three pieces of hardware that renumber it — click anything to trace a different one.

01 The array, seen from the pad side

100 grid positions, 96 of them populated. Each square is one shank; the number on it is its electrode id — the elecNN label Blackrock prints on the array. The colour is the amplifier bank that shank's wire ends up in, and that is the point of this picture: the colours are scattered, not blocked. Neighbouring electrodes go to different banks, so the wire bundle thoroughly shuffles the order before anything is recorded.

Four positions are always empty — 96 shanks on a 10×10 grid. But which four varies by array. When shanks break during manufacture, Blackrock rewires surviving ones from elsewhere, so a corner moves. Switch to implant 2 anterior above to see it. Never reuse one array's map for another.

02 The pedestal and connector

The wire bundle runs to a pedestal on the skull, whose LGA board fans the 96 wires out to four banks of 36 pins. Pins 1–32 of each bank carry signal; the last four are reference and ground. This is the part that used to be a standalone CerePort plug, and it is where bank + pin becomes the electrode's real address.

03 Amplifier, and the number in your file

The headstage samples the banks in order, and the pins in order within each bank. That sampling order is the channel id — nothing else defines it.

04 Then vs now: where part 2 ends and part 3 begins

The split matters when reading older documentation or older lab notes. The connector and the amplifier were once separate objects you could unplug from each other. Today they are one unit — but the numbering is identical, because the banks and pins did not change.

The full translation table for the selected array. The row in colour is your current selection.

Built from the array's own .cmp map file and factory workbook, and checked against the recordings: the NEV's per-channel header stores the bank and pin beside the channel id, and channel id = (bank − A) × 32 + pin holds for 96 of 96 channels on every file tested. Sources: Blackrock LB-0023 Rev 8 “Channel ID, Electrode ID, and channel index”, and the support article How to interpret and use mapfiles.

One consequence worth carrying away: the impedance files that ship with an array are indexed by pin, even though their rows are headed elecN. Reading them as electrode numbers produces a complete, plausible, wrong table.
