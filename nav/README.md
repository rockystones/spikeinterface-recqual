# nav/

Navigation ledger for this repository (schema nav/v0.2). One Markdown file per entry in `entries/`;
everything else here is generated by `nav.py build` and must never be edited by hand:
`state.json`, `STATE.md`, `DELTA.md`, `NAV.html`. If a merge conflicts on a generated file, rebuild it.

- Spec: NAV-SPEC-v0.2.md in the nav-kit checkout.
- `GLOSSARY.md` (optional): project vocabulary appended verbatim to STATE.md's Vocabulary section.
- Session rules for agents: see CLAUDE-snippet.md, meant to be pasted into the repo's CLAUDE.md.
- Hooks: hooks.example.json shows the SessionStart / PreCompact / SessionEnd wiring.

`last-review` is a git tag that marks the commit the human last read STATE.md at; `nav.py review` moves it.
DELTA.md is always relative to that tag, never to the last agent run.
